## 進め方

1. 機械的な洗い出し (スクリプト)
   - 係り結び: 句中の「ぞ・なむ・こそ」(「や・か」は目で確認) と句末の活用形を照合。
   - 現代仮名遣いの混入: 読みの「おう・こう・とう…」「ず・じ」、語中の「わいうえお」、本文の「思う・言う・おし・おど」等を列挙。
   - 本文 (text) の仮名が読み (kana) に順に含まれるか (表記と読みの食い違い)。
   - S7 の句末が連体形 (〜たる・〜るる・〜ける・〜しき 等) のもの。
2. 人手の通読: 上の結果も含め、全句を `role / 題材・気持ち / text / kana / m` の表にして 1 件ずつ読んだ。
3. 修正は text / kana / m をその場で直し (easy.js は `'text|kana|key|!'` の行と `PM` の見出しを同時に変更)、音数は role の目標を維持。`node tools/validate.mjs` (エラー 0) と `node _dev/test-easy-gen.mjs` (全合格) を確認。
4. 直した句の文面を E2E (スクラッチパッドの `e2e-*.mjs`・`ui2_*.js`) で検索 → **参照なし**。

## 保留 (直さなかったもの) と理由

- **連体止めの M7/C7** (心さびしき・逢ひ見まほしき・ゑみのこぼるる・見るもめでたき・目をうばはるる・息をのみつる・うつろひやすき・言ひ出でがたき・忘れかねつる・声にならざる・ゆるりと過ぐる・けふも暮れぬる・守らまほしき 等): 係助詞なしの連体止めは和歌で詠嘆の型として普通にある。
- **S7 が終止形で終わる句** (錦おりなす・赤くもえたつ・かささぎわたる・音もなく降る・菫咲く 等): 四段・ラ変は終止形と連体形が同じで、二句切れ・連体修飾のどちらにも読めるため成立する。「ひとときすずし」「ぽとりと落ちぬ」「やがてあがりぬ」は二句切れとして許容。
- **述語のない M7** (こころは君に・古き思ひ出・幼き日々を・遠き日のこと・時のゆるやか・風もやはらか) と **「〜に」止めの結句** (parts の 草の枕に・波路はるかに): 余情の言いさしとして許容。m で述語を補っている。
- **汎用 J5 の枕詞「ひさかたの」**: 次に「天・空・月・光」が来ないとかかり先がない。汎用から外すかどうかは生成器の側の判断が要るため、データは変えていない。
- **中世以降の語・現代寄りの語** (とんぼ・夜空・季節・木もれ日・ぼかす・しなだれ・風車・油蝉・菊日和・ぽつり/ぽとり/さっと/ざあざあ/すいすい/こんこん・夜なべ・台所・茶・吹雪く・落ち着く・めざす・緑したたる・安らぎ・杏 等): 初めての人に分かりやすい「ほんのり古典」の方針 (4 章冒頭) の範囲として許容。助動詞「たし」(声ききたしや・抱きしめたしや) と「〜ずに」(言はずにおきぬ・こころはれずに) も中世の用例があるため保留。
- **歴史的仮名遣いで判断が割れるもの**: 「心はづみて」(弾む: 辞書により はずむ/はづむ)、「ふはふは降りて」(擬態語)、words の 神無月「かんなづき」(古くは かみなづき/かむなづき)、山茶花「さざんか」(歴史的には さざんくわ で、表記どおり数えると音数が変わる)、「茶をすすりけり」の ちゃ (古くは ちや)。辞書確認のうえで決める。
- **「安らかに寝ぬ」**: 「寝 (ね)+ぬ (完了)」で正しいが、「寝ない」とも読める。
- **「思ひやまずて」**: 「ずて」は上代語で中古以降はまれ。誤りではない。
- **語義の幅**: いとほしきかな (中古は「気の毒だ」が中心、気持ち「いとおしい」のタグに合わせ現代寄りの訳)、待ちわびにけり「待ちくたびれた」。
- **words の 寂し「ひとりぼっちで心細い」、つれなし「相手の冷たいさま」**: 中心義からは外れていないため据え置き (つれなしの「平然として変わらない」の意は note 追加の候補)。

## 今後データを足すときのチェックリスト

1. **係り結び**: 句に「ぞ・なむ・や・か」があれば句末は連体形、「こそ」なら已然形。形容詞は「〜き」/「〜けれ」、下二段は「〜るる」/「〜るれ」、「寝 (ぬ)」の已然形は「ぬれ」。結ぶと音数が変わるなら係助詞を外すか語を替える。
2. **活用**: 形容詞のカリ活用 (〜かり) は助動詞に続くときだけ (「〜かりけり」はよい、「〜かり」止めは不可)。形容動詞は「〜なる/〜に」(口語の「〜な」は不可)。口語の下一段 (垂れる・離れる) を使わない。
3. **口語文法を入れない**: 格助詞「で」「が (主節の主語)」、可能動詞 (言へる・離せる)、「〜てくれる」「〜たくなる」「〜ている」。可能は「〜る/らる」、願望は「まほし」「ばや」。
4. **役割 (9.3)**: S7 は連用形・「て」「つつ」・体言で止める (連体形止めは不可)。J5 は連用形・「〜ば」「〜て」「〜の」「〜に」等で次へつなぐ。M7/C7 は言い切り・詠嘆 (けり・かな・ぬ・つ・なり・連体止め)。
5. **歴史的仮名遣い**: 語中・語尾のハ行 (思ふ・言ふ・うへ)、ワ行 (ゐ・ゑ・を: をしむ・をはる・をどる・をさなし・ゑむ・こゑ)、ぢ/づ (ふぢ・もみぢ・づつ)、漢語の字音 (峠 たうげ・皓々 かうかう・苦労 くらう・格子 かうし)。迷ったら古語辞典で確認し、音数が変わるなら句ごと替える。
6. **表記と読み**: 本文の仮名は読みにそのまま含まれること (`audit` の機械チェックと同じ)。当て字に注意 (小鹿=こじか、さを鹿=さをしか)。
7. **m (大意)**: 古語の第一義で訳す (にほふ=色が映える/香る、ながむ=物思いにふけって眺める、あはれ=しみじみとした情趣、をかし=趣がある、つれなし=冷淡だ/平然としている、かなし=いとしい/悲しい、わぶ=〜しかねて困る、すさぶ=慰みに〜する/勢いが増す、ためし=先例)。受身・他動詞の向きを取り違えない。S/J は名詞句・連用句で、M/C は述語で止める (10.1)。
8. **現代語**: 「何度」「なぞる」「ほっと」「やり遂げる」など明らかな現代語は和語に替える (あまたたび・なごむ・なし遂ぐ)。擬音語・中世以降の語は「ほんのり古典」の範囲で可。
9. **枕詞の例歌**: 実際に枕詞としてかかっている箇所を引く。作者は勅撰集の番号で確認 (よみ人しらずは集名)。確実でなければ空にする。
10. **確認**: `node tools/validate.mjs` (エラー 0) と `node _dev/test-easy-gen.mjs`。句の本文を変えたら E2E (スクラッチパッドの e2e-*.mjs) が文面を参照していないか検索する。

## 現代語の句 (easy-modern.js)

- `data/easy-modern.js` は「現代のことばも混ぜて」(DESIGN 13) 用に、`modern: true` の口語の句 621 件を `WAKA.easy.phrases` へ追加する (S5 218・S7 216・J5 30・M7 75・C7 82)。題材 72 ごとに S5 3・S7 3 (S5 のうち pos3Ok 2 以上)、気持ち 12 ごとに M7 6 以上・C7 4 以上、汎用 J5 30・汎用 C7 27。
- 方針: 平明な現代短歌の口語 (「〜してる」「〜だね」「〜かな」まで)。ネットスラング・「超/マジ/やばい」・絵文字・固有名詞・商品名は使わない。読みは現代かなづかい (ゐ・ゑ・ぢ・くわ・語尾「ふ」を使わない)。validate が kana を検査して警告する。
- 著作権: 既存の現代短歌の句の引用・酷似は避け、題材名と平易な動詞・形容詞で一から作った。有名な言い回しは使っていない (要望があれば追加で目視確認する)。
- 古風の句との重複: 「梅の花」「波の音」など、現代かなづかいの読みが古風の句と同じ句は同じ読みで別に持つ。validate の重複検査は古風と modern を分けて数える。
- 件数の閾値: 古風の最低件数 (S5 8・S7 8・汎用 J5 60 など) は modern でない句だけで数え、modern は別に 13.3 の件数で検査する。
