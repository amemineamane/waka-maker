# みんなの和歌 設置手順 (Google Apps Script)

「みんなの和歌」は、Google スプレッドシート + Apps Script のウェブアプリを投稿の受け口にします。所要 10 分ほど、費用はかかりません。

## 1. スプレッドシートを作る

1. Google ドライブで「新規」→「Google スプレッドシート」→「空のスプレッドシート」。
2. 左上の名前を「和歌メイカー みんなの和歌」などにします。

## 2. Apps Script にコードを貼る

1. スプレッドシートのメニュー「拡張機能」→「Apps Script」を開きます (新しいタブで開きます)。
2. 左の「ファイル」の `コード.gs` (または `Code.gs`) を開き、中身を全部消します。
3. このリポジトリの `gas/Code.gs` の中身を全部コピーして貼り付けます。
4. 上のフロッピーのアイコン「プロジェクトを保存」(Ctrl+S) を押します。

## 3. ウェブアプリとしてデプロイする

1. 右上の青い「デプロイ」→「新しいデプロイ」。
2. 「種類の選択」の横の歯車アイコン →「ウェブアプリ」。
3. 「説明」は空か「v1」など。
4. 「次のユーザーとして実行」は「自分」(自分のメールアドレス)。
5. 「アクセスできるユーザー」は「全員」。
6. 「デプロイ」を押します。
7. 初回は「アクセスを承認」が出ます。押して自分の Google アカウントを選びます。
8. 「Google hasn't verified this app (このアプリは Google で確認されていません)」の警告が出たら、「詳細」→「(安全ではないページ) に移動」(名前はプロジェクト名入り) →「許可」。自分で貼ったスクリプトなので問題ありません。
9. 「ウェブアプリ」の URL (`https://script.google.com/macros/s/.../exec`) が出るので「コピー」します。

## 4. 動作確認

ターミナルから (`-L` はリダイレクトを追うため必須です):

```
curl -L "<コピーしたURL>?action=ping"
```

ブラウザなら、URL の末尾に `?action=ping` を付けて開きます。

次のような表示が出れば成功です。初回はシート `posts` と `ng` も自動で作られます。

```
{"ok":true,"version":1,"count":0}
```

## 5. サイトに設定する

`data/site.js` の `minna: { api: '' }` に、コピーした URL をそのまま入れます。

```js
minna: { api: 'https://script.google.com/macros/s/.../exec' }
```

その後サイトを公開し直します。`api` が空のあいだは、サイトに「みんな」タブも投稿ボタンも出ません。

## 更新のしかた

`Code.gs` を変えたら、貼り替えて保存したあと「デプロイ」→「デプロイを管理」→ 鉛筆アイコン →「バージョン」を「新バージョン」にして「デプロイ」。URL は変わりません。(「新しいデプロイ」を選ぶと URL が変わるので注意。)

## 管理のしかた

- 不適切な投稿を隠す: シート `posts` の該当行の `hidden` 列に `1` を入れます。行は消えません。戻すときは空にします。反映は最大 20 秒ほど。
- NG ワード: シート `ng` の A 列に 1 行 1 語で書きます (部分一致、大文字小文字は区別しません)。1 行目は見出しなので使えません。歌・雅号・大意に含まれると投稿が断られます。
- 投稿者による取り下げは、サイトから自動で `hidden` が 1 になります。
- 保存されるのは、本文・読み・雅号・大意・お題の日付・端末ごとの識別子・取り下げ用の確認値 (ハッシュ) だけです。IP やアカウントは記録しません。

## 注意

- ウェブアプリの URL は公開されても構いません (サイトの JS に載る前提です)。ただし**スプレッドシート自体は共有しないでください** (リンクを知っている人に開放しない)。
- 連投は端末ごとに 20 秒に 1 回、全体で 1 分に 30 回までに制限されます。
- Google の無料枠 (1 日あたりの実行回数など) の範囲で動きます。配信などで急に増えるときは様子を見てください。
- 動かないときは、「デプロイ」→「デプロイを管理」で「アクセスできるユーザー」が「全員」になっているか確認します。
